# Dataset Download Instructions

The Sentiment140 dataset file `training.1600000.processed.noemoticon.csv` is too large (227MB) for GitHub.

## Download the dataset:
1. Go to: https://www.kaggle.com/datasets/kazanova/sentiment140
2. Download `training.1600000.processed.noemoticon.csv`
3. Place it in the Assignment2 folder

## Alternative:
Use the optimized notebook `sentiment_analysis_attention_optimized.ipynb` which works with a smaller sample of the data for demonstration purposes.
